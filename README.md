# TimeTally

Never forget to punch in or out. TimeTally lives in your Mac menu bar (Windows too) and reminds you at the right moment.

**Download:** [latest release](https://github.com/williammgyasii/timetally-releases/releases/latest), or from [timetallyapp.com](https://timetallyapp.com).

This repository holds the installers only. Installed apps update themselves from here.
